# Extension Icons

Place your extension icons here:
- `icon16.png` (16x16 pixels)
- `icon48.png` (48x48 pixels)
- `icon128.png` (128x128 pixels)

For now, you can use placeholder icons or create simple ones with:
- A green circle (representing RezPulse)
- Text "RH" (Resonate Hunter)
- Or any simple icon that represents "hunting/capturing"

You can generate icons using:
- Online tools like https://www.favicon-generator.org/
- Design tools like Figma, Canva
- Or use a simple colored square as a placeholder
